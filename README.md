# Applied AI Engineering Evidence

Публичный репозиторий проверяемых результатов 82-дневной подготовки к позиции Middle Applied AI Engineer.

## Programme

- Six 12-day sprints, three mock interviews and seven final days
- Primary track: Applied AI Engineering
- Supporting tracks: ML/LLM and DevOps
- Open-source projects: Open WebUI (sprints 1–4), Dify (sprints 5–6)

## Evidence rules

Результат подтверждается ссылкой на commit/PR, воспроизводимым выводом тестов, benchmark/evaluation с методикой, архитектурным документом, failure log или точным ответом контрольной работы без AI. Количество часов, прочитанных страниц и сгенерированных строк само по себе не является доказательством.

## AI usage policy

- До использования Agent фиксируются гипотеза и план.
- После генерации проверяются diff и тесты.
- Автор обязан защитить решение без AI.
- В контрольных задачах и mock interviews AI запрещён.

## Security

Не публикуются API keys, tokens, credentials, `.env`, персональные данные, proprietary code, datasets, model weights, виртуальные окружения и dependency directories.
